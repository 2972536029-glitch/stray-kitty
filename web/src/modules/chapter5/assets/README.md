# Warehouse ground delivery asset

`warehouse_L0_ground.lossless.webp` is a lossless delivery copy of the locked
`level_design/chapter5/art/warehouse_L0_ground.png`. The authored PNG stays unchanged.
Both decode to the same 1672 × 941 RGBA pixels, including transparent pixels.
The delivery copy is 1,194,846 bytes instead of 1,752,328 bytes (31.8% smaller).

Generated with Pillow's WebP encoder using `lossless=True, method=6, exact=True`.
The warehouse cold-entry browser test compares the actual decoded canvas pixels
against the original PNG. All map placement, geometry and masks still use the
original sources.
