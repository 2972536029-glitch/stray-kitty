# 小猫回家记：流浪猫王国 · PRD

版本：1.6｜2026-10-22｜浏览器优先，2D 像素风。后续手机／桌面应用只保留兼容方向。

## 1. 游戏目标与循环

玩家操控走失的家猫喵喵，通过探索、事件选择和分路塔防营救伙伴，把废弃花房建设成共同的家。主题：从寻找自己的家，到为伙伴创造一个家。

**探索 → 交互／事件 → 选择与骰子判定 → 获得线索和物资 → 塔防救援 → 解锁猫咪与区域 → 家园建设、家具抽奖／商城 → 下一次探索。**

## 2. 故事范围

| 章节 | 主要内容 |
| --- | --- |
| 序章：金枪鱼事件 | 喵喵追逐食物走失，学习移动与对话；主人正在寻找它，但不切换人类视角 |
| 第一章：陌生小巷 | 认识团子，营救纸箱里的点点；发现寻猫启事和伙伴失踪的线索 |
| 第二章：午夜集市 | 交换物资与情报，理解流浪猫处境；线索指向废弃花房 |
| 第三章：废弃花房 | 猫咪共同修缮据点；团子寻找路线，点点观察陷阱，墨墨侦查暗道 |
| 第四章：消失的猫咪们 | 探索暗道和仓库，识别假目标，分批营救被困伙伴 |
| 终章：点亮流浪猫王国 | 护送光源、照亮撤离路线；花房成为共同家园，喵喵与主人团聚并继续探望伙伴 |

叙事规则：猫咪主动救援与建设；黑影象征危险和恐惧、怕光，不揭露具体身份或设为鬼魂；真实动物不简单作为邪恶反派。人类仅提供有铺垫的线索与物资，不接管营救。结局保留喵喵自己的家与伙伴的家。

## 4. 核心规则

- **探索与任务**：交互需要接近目标；区域按剧情条件解锁。任务有未开始、进行中、已完成状态；一次性线索和奖励持久记录。事件失败不能永久阻断主线。
- **事件**：采用余尧 v0.3 的 2d6 四档：12 大成功（2.78%）、9–11 成功（25%）、6–8 有代价（44.44%）、2–5 失败推进（27.78%）。服务端掷骰并保存结果，刷新不能重掷；后果包统一传递资源、塔防压力、局势和剧情标记。绕路／紧急撤离先经过对应剧情再进入布防；主线猫不会因判定失败而失去救援机会。正式事件内容与数值由余尧维护。
- **塔防**：保护和营救为目标；失败可重试，不发成功奖励。局内单位、位置、生命、能量和计时留在战斗模块，永久奖励由服务端结算。正式规则与数值由闫琦雯维护。
- **猫咪**：主线伙伴通过剧情救援确定性获得，不进入随机卡池；其他模块使用同一猫咪标识和拥有状态。
- **家园**：拥有家具与已经摆放分开记录；同一件家具不能同时占两个位置，移动／替换不丢失拥有权。升级需要验证前置条件和资源。
- **花房演出**：对话期间剧情独占猫咪站位与动作，墨墨登场、伙伴分工和告别跟随当前剧情节点；日常漫游、碰鼻和家具偏好仅在家园空闲阶段启用。暂停、打开菜单和页面隐藏时停止家园时间。
- **家园阿策**：真实家园阶段由顶栏「问阿策」或点击场景里的阿策主动打开聊天，阿策采用与家园伙伴一致的 64×64 像素比例，保留奶油毛色、棕色与深色花纹、绿眼睛、绿色领巾和折扇，参与花房漫游、摸摸、拖动、家具与伙伴互动，不写入拥有伙伴或战斗阵容；沿用只读旅程问答并区分模型与本地说明；不自动弹窗。修缮说明、施工演出、家具编辑、邮局和教学优先，聊天关闭或离开场景时取消等待。欢迎语只描述当前花房；已知剧情仅使用经过主线条件筛选的短摘要，试玩通关与 QA 检查点不作为亲历剧情证据。
- **经济与背包**：货币、道具、家具各自只有一份持有记录；奖励、扣费和发放一起提交，数量不能为负，同一奖励不重复领取。
- **抽奖**：仅两个常驻主题池：免费邮票池「苔叶来信」（1 邮票/抽）与罐头付费池「月海观星」（60 罐/抽），各十二件独立家具，权重 12/10/8/10/12/8/8/6/8/6/6/6。旧家具全部随剧情确定性赠送，不进入新卡池；保留老存档家具及摆放。未集齐时最多三抽必得一件未拥有家具（两次连续重复后，按剩余家具原权重抽取）；新家具重置计数，两池独立持久化。重复转换 2 份材料，集齐后仍可抽取并明确提示补偿。家具不提供战斗数值、不作为通关条件。家具按统一的 1.7 世界像素/厘米布置：沙发约 128–135 cm、地毯约 128–138 cm、书桌约 112–116 cm，小窝约 44–108 cm、灯约 28–34 cm、摆钟约 25–26 cm；图鉴与布置预览使用同一比例，小件可单独放大看细节。
- **互动**：不同猫咪偏好不同家具，例如墨墨偏好月亮吊床、团子偏好零食抱枕、点点偏好纸箱城堡。
- **商城与邮局**：商店承接来信、猫咪心愿与旅程奖励；邮局采用通用邮寄拼贴手账，切换家具池保持同一套界面。左侧藏品每次展示一件并在当前卡池内随机轮换。主画面先展示真实花房的整套家具搭配，选择一份或十份后翻出明信片；可连续画一笔，画完松开自动寄出，也可跳过，寄出时才扣费，涂画不上传也不参与抽奖。盖邮戳后收起明信片，包裹依次落下；十连点击后在原位直接换成家具，不另播单件动画，不保留纸箱底座，也可主动全部拆开，未拆完可稍后继续。十份在同一服务端事务内按原规则抽取与累计保底，失败全部回滚，重试不重复扣费。图鉴、最近50次收据与规则独立展开；结果可进入原家具背包，旧收据回看不再扣费。支持减少动态偏好，充值返回原卡池且不自动抽取。
- **未来付费**：独立订单绑定玩家、商品快照、金额与币种；服务端验证渠道结果并去重发货。前端返回页不能发货。本次不接 SDK 或真实付款。

## 6. 界面、保存与验收

视觉接入轩扬 2.0.0 的暮色开场、城市背景、64×64 像素猫和纸木色界面，保持猫咪身份、现有剧情、探索交互与服务端状态。

花房采用单层拱顶铁艺温室的纯室内像素场景（1672×941）：南侧入口、木地板、室内花圃与中央猫咪活动区。建筑底图不含猫咪或家具，透明组件独立布置，原有像素猫保持独立绘制；大型家具遮挡和地面占位分别处理。四阶外观依次为冷灰漏雨避雨处、封窗铺毯的简易庇护所、透光复绿的原木温室、暖光灯串庆典。花房预览和场景共用建筑、家具坐标和修缮绘制，原有摆放、商店与存档继续有效；支持缩放、拖动和一键全景。家园手册、邮局、商店、章节地图、仓库和布置在原顶栏分别提供入口，沿用设置按钮的样式；顶栏不再单独展示资源余额或充值入口，不增加浮动功能面板或底部导航。

四阶段分别使用破纸箱／接雨器／枯植、拼装木桌／干稻草／补丁被、原木工作台／储粮箱／混合盆栽与苗架、庆典餐台／礼物／迎宾花灯等独立家具设计。修缮会替换对应陈设，庆典保留已经复苏的花园和明亮日照，再增加暖光与彩旗，不压暗底图；每种可购买家具使用独立图稿，默认生活区在玩家摆入家具后让位，不写入拥有记录。花草按花槽、陶盆、木桶、细藤、吊盆与墙边垂叶分层布置，中央留出剧情和活动动线。

电脑端点击顶栏「布置」后，直接在当前场景进入原有布置模式，保留原来的缩放和视角，编辑期间隐藏并暂停小猫，退出后恢复。背包从底部展开，家具横向浏览，可收起留出场景视野，默认家具与剧情／抽奖收藏家具都能直接拖动、收回和重新摆放，不再逐个选择固定槽位。背包支持场景／库存筛选，并可叠加墙饰、装饰、桌子、小窝、座椅、收纳、绿植、地毯、灯具与玩具分类及名称搜索；卡片和选中信息显示类别与参考宽度。收藏与各阶段默认家具均经过同一比例核对，尺寸读取内容目录，场景、图鉴和预览共用。背包保留撤销／重做、方向键微调；本轮仅面向电脑浏览器。拖动途中可取消本次移动，取消布置恢复进入前的整份布局；点击保存才整批提交。网络结果未知时保留草稿并重试同一请求。四阶段的默认家具各自记录位置与收纳状态，后续修缮切换阶段不会被上一阶段的收纳影响；收藏家具跨阶段保留布局。猫咪在家具的新位置互动，剧情对白继续优先接管角色。

「家园手册」包含花房总览、旅程记录、猫咪伙伴与家具收藏，分类按钮放左、介绍文案放右。旅程记录保留任务进度和已到达章节的故事回顾；伙伴的相遇状态、身份与介绍统一放入猫咪伙伴，避免重复。「章节地图」负责出发与当前主线衔接，移除原先地图中的花房图片。各模块从顶栏直接打开各自的居中窗口，设置独立显示声音设置；货币余额与补给入口只在邮局、商店等使用场景显示。关卡试玩归入验收工具，修缮继续在场景破损位置操作，悬停和按下标记时保持定位不跳动。猫国商店承接来信、猫咪心愿与旅程奖励，沿用原每日刷新和服务端签收记录；商店移除旧家具陈列，已获家具与剧情赠送保持有效。猫爪邮局专注主题包裹、开箱和收据。

修缮入口直接标在场景破损位置，右侧家园面板不再提供整阶段修缮按钮。初始阶段分为修窗（4 材料）、补屋顶（4 材料）、排水铺草（2 材料，先修窗与屋顶）；简易庇护所分为修地板（8 材料）、修天窗（7 材料＋1 邮票）、整理花架（5 材料，先修地板与天窗）。点击部位查看说明、库存和前置条件，再修补该处；修窗后木板封窗，补屋顶后停止滴雨，修天窗后透进阳光。每处进度独立保存，同阶段全部完成才升级，原有总消耗与解锁不变，庆典仍由终章剧情点亮。

修缮成功后保留施工前的画面，局部修补以约 1.9 秒的锤击、木屑与暖光过渡，整阶段升级以约 3.4 秒的施工、全屋渐显与光尘过渡，庆典阶段改用灯光点亮表现。过渡期间暂停猫咪行动并暂时隐藏修缮标记，完成后恢复；菜单、后台暂停动画，刷新读取已保存状态，不重播施工或重复扣费。减少动态效果偏好使用短暂淡入，失败请求不播放成功动画。

四套阶段家具共 48 张正向透明组件已替换原斜角图稿，与两套抽奖家具统一视角，按实际用途区分尺寸。图集及独立组件位于 `web/public/assets/home/`；素材由内置 imagegen 生成，最终提示词保存在 `scripts/home-stage-art-prompts.json`，可用 `scripts/prepare-home-stage-atlas.mjs` 从独立组件重新打包。

日常场景可直接拖动原有像素猫：落到空地会就地停留，落到家具触发该类动作，落到伙伴身边触发碰鼻、蹭蹭、互相理毛、轻拍玩耍或并排打盹。功能家具覆盖猫窝躲藏、吊床休息、坐垫踩奶、磨爪、登高、进食、嗅花、扒拉工作台／储物箱、暖灯晒肚皮、追视摆钟和拨动玩具；同类家具共享动作，所有猫保留原有外观。家具占用从接近时预留，玩一阵后离开，自动行为在活动、漫步与伙伴互动之间轮换。猫咪落点与漫步避让其他猫及家具的可见体积，折叠毛毯等有体积的软装不能当作地毯穿过；嗅闻在花箱和柜子外侧，离开家具先寻找安全地面。地毯先铺地，家具与猫按落地深度绘制，家具使用者紧接所属家具，只有最下沿遮住脚爪。拖动途中按 Esc 取消，剧情、菜单和暂停期间不能拖动；猫咪日常位置只属于当前场景模拟，家具位置仍由服务端保存。

猫咪日常对话按家具动作、伙伴互动、性格与短时情绪选择，分别有开心、平常、烦躁三组表达，同一只猫连续做同一动作会轮换台词。轻轻摸摸、连续打扰、睡觉或进食中被碰会有不同反应；暂停摸摸后烦躁自行消退。情绪只存在于当前场景，不扣奖励或修改存档。自动闲聊共用间隔，不打断玩家刚触发的对话。摸猫和拖猫命中实际绘制的轮廓，包含朝向、躺卧、跳跃与遮挡；透明部分不算命中，按下与松开须为同一只猫。家具点击仅邀请点击位置附近的空闲猫，不能隔空叫走远处或忙碌的猫；仍可主动把猫拖到目标家具。

界面覆盖：开场／加载／继续、对话与任务、探索 HUD、真实进度伙伴列表、章节地图、事件判定、准备、战斗 HUD、结算、家园、商店与暂停；家具抽奖采用套装预览、明信片涂画、包裹送达与手动拆包的连续演出，保留独立图鉴、摆放与收据。按钮有文字与焦点反馈；请求中阻止重复操作；暂停停止局内时间；邮局主界面以电脑浏览器为主。

手机网页以横屏游玩：竖屏提示旋转并暂停场景，转回横屏保留当前进度；探索提供左侧摇杆与右侧互动、攀爬等触屏按钮，松手、切后台或打开面板后清空移动输入。短屏使用单行顶栏、紧凑战斗布局和可滚动弹窗，适配刘海与底部安全区；桌面保留现有布局和键盘操作。

验收工具按序章、小巷、集市、花房、暗道和终章组织，读取服务端验收开关与节点清单。跨章跳转和指定事件使用服务端固定测试进度；首次进入前持久保存原进度，切换节点不覆盖快照，可一键返回。战斗胜负模拟仍走正常结算；面板打开时暂停场景。普通流程操作保留真实阶段与剧情前置校验。

长期进度自动保存在服务端。写命令使用版本号与幂等键；版本冲突读取最新状态，网络结果未知时重试原请求。匿名会话保存在浏览器，丢失后当前不能恢复账号；战中刷新重开本次战斗，不恢复逐帧现场。
