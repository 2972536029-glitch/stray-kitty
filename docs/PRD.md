# 小猫回家记：流浪猫王国 · PRD

版本：1.6｜2026-10-22｜浏览器优先，2D 像素风。后续手机／桌面应用只保留兼容方向。

## 1. 游戏目标与循环

玩家操控走失的家猫喵喵，通过探索、事件选择和分路塔防营救伙伴，把废弃花房建设成共同的家。主题：从寻找自己的家，到为伙伴创造一个家。

**探索 → 交互／事件 → 选择与骰子判定 → 获得线索和物资 → 塔防救援 → 解锁猫咪与区域 → 家园建设、家具抽奖／商城 → 下一次探索。**

## 2. 故事范围

叙事规则：猫咪主动救援与建设；黑影象征危险和恐惧、怕光，不揭露具体身份或设为鬼魂；真实动物不简单作为邪恶反派。人类仅提供有铺垫的线索与物资，不接管营救。结局保留喵喵自己的家与伙伴的家。

## 4. 核心规则

- **探索与任务**：交互需要接近目标；区域按剧情条件解锁。任务有未开始、进行中、已完成状态；一次性线索和奖励持久记录。事件失败不能永久阻断主线。
- **事件**：采用余尧 v0.3 的 2d6 四档：12 大成功（2.78%）、9–11 成功（25%）、6–8 有代价（44.44%）、2–5 失败推进（27.78%）。服务端掷骰并保存结果，刷新不能重掷；后果包统一传递资源、塔防压力、局势和剧情标记。绕路／紧急撤离先经过对应剧情再进入布防；主线猫不会因判定失败而失去救援机会。正式事件内容与数值由余尧维护。
- **塔防**：保护和营救为目标；失败可重试，不发成功奖励。局内单位、位置、生命、能量和计时留在战斗模块，永久奖励由服务端结算。正式规则与数值由闫琦雯维护。
- **猫咪**：主线伙伴通过剧情救援确定性获得，不进入随机卡池；其他模块使用同一猫咪标识和拥有状态。
- **家园**：拥有家具与已经摆放分开记录；同一件家具不能同时占两个位置，移动／替换不丢失拥有权。升级需要验证前置条件和资源。
- **花房演出**：对话期间剧情独占猫咪站位与动作，墨墨登场、伙伴分工和告别跟随当前剧情节点；日常漫游、碰鼻和家具偏好仅在家园空闲阶段启用。暂停、打开菜单和页面隐藏时停止家园时间。
- **家园阿策**：真实家园阶段由顶栏「问阿策」或点击场景里的阿策主动打开聊天，阿策采用与家园伙伴一致的 64×64 像素比例，保留奶油毛色、棕色与深色花纹、绿眼睛、绿色领巾和折扇，参与花房漫游、摸摸、拖动、家具与伙伴互动，不写入拥有伙伴或战斗阵容；沿用只读旅程问答并区分模型与本地说明；不自动弹窗。修缮说明、施工演出、家具编辑、邮局和教学优先，聊天关闭或离开场景时取消等待。欢迎语只描述当前花房；已知剧情仅使用经过主线条件筛选的短摘要，试玩通关与 QA 检查点不作为亲历剧情证据。
- **经济与背包**：货币、道具、家具各自只有一份持有记录；奖励、扣费和发放一起提交，数量不能为负，同一奖励不重复领取。
- **抽奖**：仅两个常驻主题池：免费邮票池「苔叶来信」（1 邮票/抽）与罐头付费池「月海观星」（60 罐/抽），各十二件独立家具，权重 12/10/8/10/12/8/8/6/8/6/6/6。旧家具全部随剧情确定性赠送，不进入新卡池；保留老存档家具及摆放。未集齐时最多三抽必得一件未拥有家具（两次连续重复后，按剩余家具原权重抽取）；新家具重置计数，两池独立持久化。重复转换 2 份材料，集齐后仍可抽取并明确提示补偿。家具不提供战斗数值、不作为通关条件。家具按统一的 1.7 世界像素/厘米布置：沙发约 128–135 cm、地毯约 128–138 cm、书桌约 112–116 cm，小窝约 44–108 cm、灯约 28–34 cm、摆钟约 25–26 cm；图鉴与布置预览使用同一比例，小件可单独放大看细节。
- **互动**：不同猫咪偏好不同家具，例如墨墨偏好月亮吊床、团子偏好零食抱枕、点点偏好纸箱城堡。
- **手册与补给**：手册集中展示花房、旅程、伙伴与家具收藏，正文至少16px，主要操作18px。家具可筛选、搜索并进入对应布置位置。补给整合领取奖励、真实材料与线索库存，移除独立仓库菜单及固定演示携带清单。章节地图展示真实场景缩略图、当前位置、解锁条件和主线下一步。
- **电脑界面**：花房菜单依次为布置、手册、邮局、补给、地图、设置。新手教程高亮跟随布置按钮，说明卡放在菜单下方，不遮挡入口。窗口缩小时，顶部菜单按桌面基准比例放大 40%；剧情对话、功能弹窗、花房修缮标记、日常气泡和布置背包在等比基础上放大 20%，最高保持原设计大小；移除功能弹窗单独的较大最小比例，统一限制在窗口内。场景锚点仍按屏幕坐标定位，缩放不改变家具摆放或点击位置。手册、补给、地图、设置、验收、游记及邮局手册统一纸色窗口、线性图标、标题 28／分区 20／正文 18／辅助 14px、24px 内边距与 42px 操作按钮；较小电脑窗口随统一比例缩放，长内容在标题下方滚动。旅程记录使用单列，独立窗口与手册内对应页按内容收口。充值窗口按内容收口，余额仅显示罐头图标和数量，保留金色礼包和棕红支付按钮；邮局主界面的美术与布局保持原样。剧情头像在对话框内垂直居中；「跳过剧情」连续推进至下一个选择、场景切换或战斗入口，不代选。
- **充值与领取提示**：充值页只展示余额、礼包数量与价格、支付操作及可展开记录。支付跳转前记住当前面板、礼包和家具池，返回后自动恢复；只根据服务端新增确认流水显示到账小窗并刷新余额。任务领取成功也显示实际获得的邮票、罐头；小窗点击任意位置关闭，失败不显示成功，重试不重复领取。
- **修缮后的布置**：前两阶段保留既有陈设，第三、四阶段均默认摆放10件，额外家具进入背包，自行选择布置；已保存的位置与收纳状态延续到后续阶段。
- **商城与邮局**：商店承接来信、猫咪心愿与旅程奖励；邮局采用通用邮寄拼贴手账，切换家具池保持同一套界面。左栏藏品每次展示一件并随机轮换，进入绘画与拆包后暂时隐藏。右侧撕边纸展示十二件真实家具的搭配特写，地板与墙面仅作布景；套装名采用手写字体，邮票与罐头使用同款带图标余额牌。点击「已收藏」展开家具图鉴，规则手册内统一查看玩法与最近50次收据。选择一份或十份后翻出重新绘制的猫咪家园明信片，邮编格、地址、邮票与邮戳随卡面比例缩放，整张纸都能连续画一笔，羽毛笔尖跟随鼠标与触摸。画完松开自动寄出，也可跳过；寄出时才扣费，涂画不上传、不参与抽奖。包裹落下后由玩家点击拆开，十连在原格子内松绳、展开纸盒并浮现家具，不跳转单件结果页、不保留纸箱底座；包裹保持方正比例并充分使用展示空间。跳过涂画、全部拆开与回到套装始终沿用单抽/十连按钮的共同中心。未拆完可稍后继续，旧收据回看不扣费。十份沿用同一服务端事务、保底及重复补偿规则，失败全部回滚，重试不重复扣费；获得家具可进入原背包布置。支持减少动态偏好，正式窗口较小时整体缩放保留布局，充值返回原卡池且不自动抽取。
- **未来付费**：独立订单绑定玩家、商品快照、金额与币种；服务端验证渠道结果并去重发货。前端返回页不能发货。本次不接 SDK 或真实付款。

## 6. 界面、保存与验收

视觉接入轩扬 2.0.0 的暮色开场、城市背景、64×64 像素猫和纸木色界面，保持猫咪身份、现有剧情、探索交互与服务端状态。

花房采用单层拱顶铁艺温室的纯室内像素场景（1672×941）：南侧入口、木地板、室内花圃与中央猫咪活动区。建筑底图不含猫咪或家具，透明组件独立布置，原有像素猫保持独立绘制；大型家具遮挡和地面占位分别处理。四阶外观依次为冷灰漏雨避雨处、封窗铺毯的简易庇护所、透光复绿的原木温室、暖光灯串庆典。花房预览和场景共用建筑、家具坐标和修缮绘制，原有摆放、商店与存档继续有效；支持滚轮缩放与拖动，场景不再常驻全景及加减按钮。家园手册、邮局、补给、章节地图和布置在原顶栏分别提供入口，沿用设置按钮的样式；顶栏不再单独展示资源余额或充值入口，不增加浮动功能面板或底部导航。

四阶段分别使用破纸箱／接雨器／枯植、拼装木桌／干稻草／补丁被、原木工作台／储粮箱／混合盆栽与苗架、庆典餐台／礼物／迎宾花灯等独立家具设计。修缮会替换对应陈设，庆典保留已经复苏的花园和明亮日照，再增加暖光与彩旗，不压暗底图；每种可购买家具使用独立图稿，默认生活区在玩家摆入家具后让位，不写入拥有记录。花草按花槽、陶盆、木桶、细藤、吊盆与墙边垂叶分层布置，中央留出剧情和活动动线。

电脑端点击顶栏「布置」后，直接在当前场景进入原有布置模式，保留原来的缩放和视角，编辑期间隐藏并暂停小猫，退出后恢复。背包从底部展开，家具横向浏览，可收起留出场景视野，默认家具与剧情／抽奖收藏家具都能直接拖动、收回和重新摆放，不再逐个选择固定槽位。背包仅列未摆放家具，保留墙饰、装饰、桌子、小窝、座椅、收纳、绿植、地毯、灯具与玩具分类，空分类显示 0；家具上方显示名称，下方提供确定、取消与收回图标。收藏与各阶段默认家具均经过同一比例核对，尺寸读取内容目录，场景、图鉴和预览共用。背包保留撤销／重做、方向键微调；本轮仅面向电脑浏览器。拖动途中可取消本次移动，取消布置恢复进入前的整份布局；点击保存才整批提交。网络结果未知时保留草稿并重试同一请求。四阶段的默认家具各自记录位置与收纳状态，后续修缮切换阶段不会被上一阶段的收纳影响；收藏家具跨阶段保留布局。猫咪在家具的新位置互动，剧情对白继续优先接管角色。

「家园手册」包含花房总览、旅程记录、猫咪伙伴与家具收藏，分类按钮置于紧凑标题下方。旅程记录保留任务进度和已到达章节的故事回顾；伙伴的相遇状态、身份与介绍统一放入猫咪伙伴，避免重复。「章节地图」负责出发与当前主线衔接，移除原先地图中的花房图片。各模块从顶栏直接打开各自的居中窗口，设置独立显示声音设置；货币余额与补给入口只在邮局、商店等使用场景显示。关卡试玩归入验收工具，修缮继续在场景破损位置操作，悬停和按下标记时保持定位不跳动。猫国商店承接来信、猫咪心愿与旅程奖励，沿用原每日刷新和服务端签收记录；商店移除旧家具陈列，已获家具与剧情赠送保持有效。猫爪邮局专注主题包裹、开箱和收据。

修缮入口直接标在场景破损位置，右侧家园面板不再提供整阶段修缮按钮。初始阶段分为修窗（4 材料）、补屋顶（4 材料）、排水铺草（2 材料，先修窗与屋顶）；简易庇护所分为修地板（8 材料）、修天窗（7 材料＋1 邮票）、整理花架（5 材料，先修地板与天窗）。点击部位查看说明、库存和前置条件，再修补该处；修窗后木板封窗，补屋顶后停止滴雨，修天窗后透进阳光。每处进度独立保存，同阶段全部完成才升级，原有总消耗与解锁不变，庆典仍由终章剧情点亮。

修缮成功后保留施工前的画面，局部修补以约 1.9 秒的锤击、木屑与暖光过渡，整阶段升级以约 3.4 秒的施工、全屋渐显与光尘过渡，庆典阶段改用灯光点亮表现。过渡期间暂停猫咪行动并暂时隐藏修缮标记，完成后恢复；菜单、后台暂停动画，刷新读取已保存状态，不重播施工或重复扣费。减少动态效果偏好使用短暂淡入，失败请求不播放成功动画。

四套阶段家具共 48 张正向透明组件已替换原斜角图稿，与两套抽奖家具统一视角，按实际用途区分尺寸。图集及独立组件位于 `web/public/assets/home/`；素材由内置 imagegen 生成，最终提示词保存在 `scripts/home-stage-art-prompts.json`，可用 `scripts/prepare-home-stage-atlas.mjs` 从独立组件重新打包。

日常场景可直接拖动原有像素猫：落到空地会就地停留，落到家具触发该类动作，落到伙伴身边触发碰鼻、蹭蹭、互相理毛、轻拍玩耍或并排打盹。功能家具覆盖猫窝躲藏、吊床休息、坐垫踩奶、磨爪、登高、进食、嗅花、扒拉工作台／储物箱、暖灯晒肚皮、追视摆钟和拨动玩具；同类家具共享动作，所有猫保留原有外观。家具占用从接近时预留，玩一阵后离开，自动行为在活动、漫步与伙伴互动之间轮换。猫咪落点与漫步避让其他猫及家具的可见体积，折叠毛毯等有体积的软装不能当作地毯穿过；嗅闻在花箱和柜子外侧，离开家具先寻找安全地面。地毯先铺地，家具与猫按落地深度绘制，家具使用者紧接所属家具，只有最下沿遮住脚爪。拖动途中按 Esc 取消，剧情、菜单和暂停期间不能拖动；猫咪日常位置只属于当前场景模拟，家具位置仍由服务端保存。

猫咪日常对话按家具动作、伙伴互动、性格与短时情绪选择，分别有开心、平常、烦躁三组表达，同一只猫连续做同一动作会轮换台词。轻轻摸摸、连续打扰、睡觉或进食中被碰会有不同反应；暂停摸摸后烦躁自行消退。情绪只存在于当前场景，不扣奖励或修改存档。自动闲聊共用间隔，不打断玩家刚触发的对话。摸猫和拖猫命中实际绘制的轮廓，包含朝向、躺卧、跳跃与遮挡；透明部分不算命中，按下与松开须为同一只猫。家具点击仅邀请点击位置附近的空闲猫，不能隔空叫走远处或忙碌的猫；仍可主动把猫拖到目标家具。

标题页未登录时以「登录」为主入口，小字「暂不登录」继续本机游客旅程；成功登录或注册后按玩家身份记住本机状态，下次直接「继续冒险」，不保存密码。首页故事文案只保留文字，不使用底板。移除商店、重开及底部状态文案。所有章节与序章演出共用底部固定的纸质对话框：右上角跳过每次只推进一段，点击面板任意非交互区域继续，不另设继续按钮；键盘一次仅推进一个节点，序章覆盖层阻止后台剧情同时响应。开场毛毯按地面透视绘制在猫咪下方，不遮挡身体与爪子。电脑端对话框接近全宽、默认占底部约四分之一，正文随窗口放大，短屏紧凑显示。

第一章探索提示恢复物件旁的名称浮签与猫咪头顶 E 键帽，木箱攀爬、狭缝保留 C／Q 提醒；物件造型与缩放保留，纸箱猫采用与主角接近的体型。其余章节名称与 Q 查看提示仍以透明文字显示在画面中央。点击或按键打开居中的详情与事件面板。事件选择、双骰动画与结果共用画面中央的纸张位置，默认只展示故事、行动与掷骰，规则可展开查看，伙伴技能与鼓励入口保留。立体双骰连续翻滚后按服务端点数落定，结果不显示零变化项。

顶栏固定在屏幕上方，独立按钮直接叠在场景上，标题与章节／地点信息放大，不再单列阶段与地图工具条；移除小地图及其点击拦截，顶栏与按钮不使用磨砂背景。老黄沿用猫咪的像素轮廓与配色层次。猫爪邮局直接打开完整抽卡书页，统一右上角关闭；在花房剧情中打开邮局也可抽取，保留对白节点与验收前存档；任务与补给入口改名「猫咪补给站」。设置接入既有账号登录／注册，可将当前旅程绑定账号跨设备取回，并提供二次确认的清空本机旅程入口，保留已绑定账号的服务器存档。

剧情框使用可超出纸框的大角色形象与大名字，移除常驻手记眉标，跳过按钮扩大；顶栏按钮透明，菜单与设置不再提供暂停入口。家园修缮标记与详情面板扩大，日常对白采用跟随猫咪的紧凑清晰气泡，互动姿态保留猫咪原体型。初始花房默认陈设按休息区与工具区重排，接水容器对应原漏雨处，已保存的自定义摆放继续优先。

界面覆盖：开场／加载／继续、对话与任务、探索 HUD、真实进度伙伴列表、章节地图、事件判定、准备、战斗 HUD、结算、家园、商店与暂停；家具抽奖采用套装预览、明信片涂画、包裹送达与手动拆包的连续演出，保留独立图鉴、摆放与收据。按钮有文字与焦点反馈；请求中阻止重复操作；暂停停止局内时间；邮局主界面以电脑浏览器为主。

手机网页综合手机设备信息、触摸能力与尺寸启用竖屏呈现，嵌入网页同样生效，并提供固定启用的手机入口（display=phone）；游戏画面整体顺时针旋转 90°，复用电脑端的界面比例与窗口样式，不单独放大菜单或弹窗。用独立同源画布视口统一旋转场景、原生弹窗和触摸坐标；背景铺满浏览器实际可见区域；安全区换算到旋转后的界面内，按钮、菜单、对话与弹窗避让状态栏及缺口，画面外不保留纯色边条。首次触摸后在支持的浏览器请求全屏和竖屏方向锁定；浏览器不支持锁定时补偿系统旋转，保持同一布局而不缩成窄条。方向与浏览器工具栏变化不重建场景或战斗，释放摇杆输入。顶部菜单与电脑端一样透明，剧情点击不显示浏览器蓝色触摸高亮。探索使用加大的透明左摇杆与右侧单个透明交互按钮，以描边和居中的猫爪图标保持可辨认，不显示按钮文字，保留无障碍名称；交互按钮复用当前地图可触发的操作，靠近目标时自动选择攀爬、钻缝、下行或跳跃，按下时只执行一个动作。松手、切后台或打开面板后清空移动输入。桌面保留现有布局和键盘操作。阿策教学卡可使用棋盘下方预留区域，正文随宽度和内容重新测量，避免折叠在狭窄空隙中。

手机与电脑在登录界面打开后共用静态资源缓存：当前界面先加载，空闲后按文件大小逐步下载其余图片、字体、声音、脚本与样式，最多一个低优先级后台请求，不提前解码图片。交互、当前图片与接口加载时中断并延后后台传输，离线、后台、省流量及很慢的网络暂停预取。已下载资源跨页面复用；资源按内容版本更新，HTML、账号、存档及支付接口不缓存。浏览器不支持缓存或存储不足时保留正常在线加载。

验收工具按序章、小巷、集市、花房、暗道和终章组织，读取服务端验收开关与节点清单。跨章跳转和指定事件使用服务端固定测试进度；首次进入前持久保存原进度，切换节点不覆盖快照，可一键返回。战斗胜负模拟仍走正常结算；面板打开时暂停场景。普通流程操作保留真实阶段与剧情前置校验。

长期进度自动保存在服务端。写命令使用版本号与幂等键；版本冲突读取最新状态，网络结果未知时重试原请求。匿名会话保存在浏览器，丢失后当前不能恢复账号；战中刷新重开本次战斗，不恢复逐帧现场。
