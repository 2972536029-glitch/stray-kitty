# 小猫回家记：流浪猫王国 · PRD

版本：1.6｜2026-10-22｜浏览器优先，2D 像素风。后续手机／桌面应用只保留兼容方向。

## 1. 游戏目标与循环

玩家操控走失的家猫喵喵，通过探索、事件选择和分路塔防营救伙伴，把废弃花房建设成共同的家。主题：从寻找自己的家，到为伙伴创造一个家。

**探索 → 交互／事件 → 选择与骰子判定 → 获得线索和物资 → 塔防救援 → 解锁猫咪与区域 → 家园建设、家具抽奖／商城 → 下一次探索。**

## 2. 故事范围

| 章节 | 主要内容 |
| --- | --- |
| 序章：金枪鱼事件 | 喵喵追逐食物走失，学习移动与对话；主人正在寻找它，但不切换人类视角 |
| 第一章：陌生小巷 | 认识团子，营救纸箱里的点点；发现寻猫启事和伙伴失踪的线索 |
| 第二章：午夜集市 | 交换物资与情报，理解流浪猫处境；线索指向废弃花房 |
| 第三章：废弃花房 | 猫咪共同修缮据点；团子寻找路线，点点观察陷阱，墨墨侦查暗道 |
| 第四章：消失的猫咪们 | 探索暗道和仓库，识别假目标，分批营救被困伙伴 |
| 终章：点亮流浪猫王国 | 护送光源、照亮撤离路线；花房成为共同家园，喵喵与主人团聚并继续探望伙伴 |

叙事规则：猫咪主动救援与建设；黑影象征危险和恐惧、怕光，不揭露具体身份或设为鬼魂；真实动物不简单作为邪恶反派。人类仅提供有铺垫的线索与物资，不接管营救。结局保留喵喵自己的家与伙伴的家。

## 4. 核心规则

- **探索与任务**：交互需要接近目标；区域按剧情条件解锁。任务有未开始、进行中、已完成状态；一次性线索和奖励持久记录。事件失败不能永久阻断主线。
- **事件**：采用余尧 v0.3 的 2d6 四档：12 大成功（2.78%）、9–11 成功（25%）、6–8 有代价（44.44%）、2–5 失败推进（27.78%）。服务端掷骰并保存结果，刷新不能重掷；后果包统一传递资源、塔防压力、局势和剧情标记。绕路／紧急撤离先经过对应剧情再进入布防；主线猫不会因判定失败而失去救援机会。正式事件内容与数值由余尧维护。
- **塔防**：保护和营救为目标；失败可重试，不发成功奖励。局内单位、位置、生命、能量和计时留在战斗模块，永久奖励由服务端结算。正式规则与数值由闫琦雯维护。
- **猫咪**：主线伙伴通过剧情救援确定性获得，不进入随机卡池；其他模块使用同一猫咪标识和拥有状态。
- **家园**：拥有家具与已经摆放分开记录；同一件家具不能同时占两个位置，移动／替换不丢失拥有权。升级需要验证前置条件和资源。
- **花房演出**：对话期间剧情独占猫咪站位与动作，墨墨登场、伙伴分工和告别跟随当前剧情节点；日常漫游、碰鼻和家具偏好仅在家园空闲阶段启用。暂停、打开菜单和页面隐藏时停止家园时间。
- **经济与背包**：货币、道具、家具各自只有一份持有记录；奖励、扣费和发放一起提交，数量不能为负，同一奖励不重复领取。
- **抽奖**：仅两个常驻主题池：免费邮票池「苔叶来信」（1 邮票/抽）与罐头付费池「月海观星」（60 罐/抽），各十二件独立家具，权重 12/10/8/10/12/8/8/6/8/6/6/6。旧家具全部随剧情确定性赠送，不进入新卡池；保留老存档家具及摆放。未集齐时最多三抽必得一件未拥有家具（两次连续重复后，按剩余家具原权重抽取）；新家具重置计数，两池独立持久化。重复转换 2 份材料，集齐后仍可抽取并明确提示补偿。家具不提供战斗数值、不作为通关条件。家具按统一的 1.7 世界像素/厘米布置：沙发约 175–185 cm、地毯约 185–190 cm、书桌约 150–155 cm，灯约 34–38 cm、摆钟约 28–30 cm；图鉴与布置预览使用同一比例，小件可单独放大看细节。
- **互动**：不同猫咪偏好不同家具，例如墨墨偏好月亮吊床、团子偏好零食抱枕、点点偏好纸箱城堡。
- **商城与邮局**：商店展示剧情纪念家具，禁止再次收费；邮局展示两套实物预览、概率、拥有状态、保底、开箱与最近 50 次收据。开箱为纸箱拆封、暖光粒子和家具展示，可直接进入家具背包拖拽布置；猫咪使用专属动作，剧情期间由剧情接管。充值不足时可进入补给小站，返回原卡池，不自动扣币。
- **未来付费**：独立订单绑定玩家、商品快照、金额与币种；服务端验证渠道结果并去重发货。前端返回页不能发货。本次不接 SDK 或真实付款。

## 5. 周一 Demo

开场／继续存档 → 序章 → 小巷移动 → 纸箱事件与骰子 → 战斗准备 → 三路塔防 → 营救点点 → 寻猫启事与决定 → 返回花房购买／摆放家具 → 刷新恢复。展示版提前开放家园以验证完整循环。

当前参考数值：三路五列、两轮六个影子、允许漏过三个；光源消耗两格能量，每四秒恢复一格；双骰参考后果使下场黑影压力为 −1／0／+1，对应移动速度 80%／100%／120%；能量保持六格，旧单骰存档仍保留原有加成。首次救援奖励为点点、纸箱猫窝、两张邮票、三份材料。主题池与剧情赠品互相独立；每日回家来信与完成布置心愿各给 1 邮票（北京时间零点重置），救援里程碑 3 邮票、集市胜利 2 邮票+30 罐、原木温室修缮 2 邮票+30 罐、终章完成 3 邮票+60 罐，各档只领取一次。模拟充值仍为 6 元/60 罐、12 元/150 罐、30 元/400 罐，4242 开头成功、0000 开头失败。

## 6. 界面、保存与验收

视觉接入轩扬 2.0.0 的暮色开场、城市背景、64×64 像素猫和纸木色界面，保持猫咪身份、现有剧情、探索交互与服务端状态。

花房采用单层拱顶铁艺温室的纯室内像素场景（1672×941）：南侧入口、木地板、室内花圃与中央猫咪活动区。建筑底图不含猫咪或家具，透明组件独立布置，原有像素猫保持独立绘制；大型家具遮挡和地面占位分别处理。四阶外观依次为冷灰漏雨避雨处、封窗铺毯的简易庇护所、透光复绿的原木温室、暖光灯串庆典。场景和章节地图共用建筑、家具坐标和修缮绘制，原有摆放、商店与存档继续有效；支持缩放、拖动和一键全景，家园面板可收起观看日常。

四阶段分别使用破纸箱／接雨器／枯植、拼装木桌／干稻草／补丁被、原木工作台／储粮箱／混合盆栽与苗架、庆典餐台／礼物／迎宾花灯等独立家具设计。修缮会替换对应陈设，庆典保留已经复苏的花园和明亮日照，再增加暖光与彩旗，不压暗底图；每种可购买家具使用独立图稿，默认生活区在玩家摆入家具后让位，不写入拥有记录。花草按花槽、陶盆、木桶、细藤、吊盆与墙边垂叶分层布置，中央留出剧情和活动动线。

电脑端打开「家具背包」即进入布置模式，背包从底部展开，家具横向浏览，可收起留出场景视野，默认家具与剧情／抽奖收藏家具都能直接拖动、收回和重新摆放，不再逐个选择固定槽位。背包支持筛选场景／库存、搜索、撤销／重做、方向键微调；本轮仅面向电脑浏览器。拖动途中可取消本次移动，取消布置恢复进入前的整份布局；点击保存才整批提交。网络结果未知时保留草稿并重试同一请求。四阶段的默认家具各自记录位置与收纳状态，后续修缮切换阶段不会被上一阶段的收纳影响；收藏家具跨阶段保留布局。猫咪在家具的新位置互动，剧情对白继续优先接管角色。

四套阶段家具共 48 张正向透明组件已替换原斜角图稿，与两套抽奖家具统一视角，按实际用途区分尺寸。图集及独立组件位于 `web/public/assets/home/`；素材由内置 imagegen 生成，最终提示词保存在 `scripts/home-stage-art-prompts.json`，可用 `scripts/prepare-home-stage-atlas.mjs` 从独立组件重新打包。

日常场景可直接拖动原有像素猫：落到空地会就地停留，落到家具触发该类动作，落到伙伴身边触发碰鼻、蹭蹭、互相理毛、轻拍玩耍或并排打盹。功能家具覆盖猫窝躲藏、吊床休息、坐垫踩奶、磨爪、登高、进食、嗅花、扒拉工作台／储物箱、暖灯晒肚皮、追视摆钟和拨动玩具；同类家具共享动作，所有猫保留原有外观。家具占用从接近时预留，玩一阵后离开，自动行为在活动、漫步与伙伴互动之间轮换。猫咪落点与漫步避让其他猫，家具使用者单独绘制在家具之后，只有最下沿遮住脚爪。拖动途中按 Esc 取消，剧情、菜单和暂停期间不能拖动；猫咪日常位置只属于当前场景模拟，家具位置仍由服务端保存。

界面覆盖：开场／加载／继续、对话与任务、探索 HUD、真实进度伙伴列表、章节地图、事件判定、准备、战斗 HUD、结算、家园、家具商店与暂停；主题抽奖已含独立开箱结果、摆放与收据；后续补齐完整图鉴和正式订单。按钮有文字与焦点反馈；请求中阻止重复操作；暂停停止局内时间；窄屏主要操作可达。

验收工具按序章、小巷、集市、花房、暗道和终章组织，读取服务端验收开关与节点清单。跨章跳转和指定事件使用服务端固定测试进度；首次进入前持久保存原进度，切换节点不覆盖快照，可一键返回。战斗胜负模拟仍走正常结算；面板打开时暂停场景。普通流程操作保留真实阶段与剧情前置校验。

长期进度自动保存在服务端。写命令使用版本号与幂等键；版本冲突读取最新状态，网络结果未知时重试原请求。匿名会话保存在浏览器，丢失后当前不能恢复账号；战中刷新重开本次战斗，不恢复逐帧现场。

| 验收 | 通过条件 |
| --- | --- |
| 首段旅程 | 能真实移动、交互、选择、战斗、营救与摆放，下一目标明确 |
| 失败路径 | 骰子失败仍可救援；战斗失败无成功奖励且可重试；资格／资源不足不部分扣费 |

| 模块接入 | 正式模块替换样例后，成功／失败／退出路径可操作，退出释放监听和计时器 |
| 后续系统 | 成长、升级、道具、抽奖与购买均验证条件、消耗、结果和重复请求；付费通知不能伪造或重复发货 |
