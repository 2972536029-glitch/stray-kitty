更新：2026-10-26。本文件描述当前无道具、无休整、六波版本；旧九步／十波／补给／免费重整版本可从Git历史追溯，不作为本轮规则。

## 当前教程

绒绒仍在场移A4 → 斑斑移B5 → 从0观察每秒5能量的自动蓄能 → 使用斑斑护盾 → 使用绒绒十字技能。木偶不反击，不计战绩；强制操作等待停表，蓄能练习按模拟时间真实推进。技能仍从猫旁按钮释放，保留范围预览、鼠标／触摸／键盘操作。

实战六波。全部战斗道具、背包、物品补能、休整、退场再部署和免费本波重整已移除。体力0才退场，本场不能复活；第3漏或两猫全部退场失败。缩为六波后保留原巡逻伤害10、疾行伤害7。

## 宿主与时钟

App → BattleHost → L00BattleHost → BattleViewport → PrologueBattle。只使用服务attempt和保存的事件难度。宿主暂停、标题、页面隐藏、军师、拖动和操作教学等待优先；正常倍速、查看半速、瞄准常速统一作用于自动蓄能、移动、攻击与护盾。

同一运行器重复start同attempt保留已有局内状态；终态结果只报告一次。整页刷新仍从该服务场次的ready重新构建，当前不做逐帧存档。失败通过主流程创建新attempt重新教学。
