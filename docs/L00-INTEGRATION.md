# L00 新手教学接入

更新：2026-10-28。本文件描述当前无道具、无休整、六波的实战引导版本；旧木偶练习、固定格移动、九步／十波／补给／免费重整版本可从Git历史追溯。

正式入口是开场剧情后的l00_tutorial，3行×7列、六波、两猫。alley_rescue现在由第一章四猫首领模块处理；首次救援与教学完成标志分开，避免再次打一遍新手教程。

## 当前教程

救援后移动仍在场的绒绒到任意合法的不同格子（A4 只是建议）→ 说明保护目标并开始真实第一波 → 黑影进入可见范围时暂停，引导玩家移动斑斑（B5 只是拦截建议，其他合法位置同样接受）→ 恢复真实战斗，以 0.5 倍速要求再移动任意一只伙伴，亲眼看到移动与敌人进攻同时发生 → 继续实战自动蓄能 → 满能且有可见黑影时依次教学护盾与十字技能，后者须覆盖真实黑影。引导完成后延续当前波次、敌人、血量和能量，不清场、不从第一波重新开战。

木偶练习已取消。操作教学用局部高亮、半透明遮罩、明确手势箭头和贴合棋盘的猫头短卡，重点文字使用大字，只说明眼前的一项操作。桌面提示放在棋盘内空处；窄屏棋盘高度不足时贴边向场景延展，优先露出猫咪、落点与箭头。移动步骤同时显示整个棋盘的合法落点，避免把推荐格误解为固定站位。推荐优先使用 A4／B5；若被引导的猫已经站在该格，箭头和地格标记会改指另一合法格。首次移动与技能操作等待时停表；第二次移动的 `teach_live_move` 阶段持续真实进攻与蓄能，固定 0.5 倍速，完成任意伙伴的合法移动才继续。玩家主动暂停仍优先。B1、B7、黑影占据格和棋盘外不可部署；退场猫不能再次上阵。角色若在实战中退场会跳过其技能教学，避免等待一个已无法操作的对象。

技能仍从猫旁按钮释放，保留范围预览、鼠标／触摸／键盘操作。每猫每模拟秒自然增加 5 能量，攻击不额外增加，满 100 后由玩家手动使用；关闭或取消选区不会扣能量。

实战六波。全部战斗道具、背包、物品补能、休整、退场再部署和免费本波重整已移除。体力0才退场，本场不能复活；第3漏或两猫全部退场失败。缩为六波后保留原巡逻伤害10、疾行伤害7。

## 宿主与时钟

App → BattleHost → L00BattleHost → BattleViewport → PrologueBattle。只使用服务attempt和保存的事件难度。宿主暂停、标题、页面隐藏和军师优先；暂停教学等待停表，实战移动教学维持 0.5 倍速。正常倍速、查看半速、瞄准常速统一作用于自动蓄能、移动、攻击与护盾。

对齐 main `6ad47e9` 时，保留最新剧情与章节推进，教学入口使用本模块真实棋盘，接替临时文字教学页。宿主准备失败只显示可诊断错误，不直接报告胜利；活动战斗期间，验收栏也不直接提交胜利或用延时跨章跳转。战斗目标提示优先于第三／第四章剧情标记。

同一运行器重复start同attempt保留已有局内状态；终态结果只报告一次。整页刷新仍从该服务场次的ready重新构建，当前不做逐帧存档。失败通过主流程创建新attempt重新教学。
