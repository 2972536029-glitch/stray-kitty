# 第五章终极仓库接入

更新：2026-10-27。第五章在个人分支 `feat/battle-l05-finale` 开发，基于第四章 `8502eb0`，继续依赖前章战斗与 carry 交付链。本轮制作可玩的终章初版，不自动合并 main、创建或改写既有 MR。当前地图、角色和具体数值见[终极仓库设计](../design/tower-defense/levels/L05-final-warehouse/design.md)及[运行配置](../web/src/modules/battle/finale/config.ts)。

## 入口与正式剧情边界

新增 `finale_boss`，完成第一章救援、已有 `alley_rescued` 后从家园进入“第五章·终极仓库”独立试玩，无须按第二至第四章顺序完成试玩。catalog 的 `lanes=7`、`columns=12`、`waves=10` 描述包围尺寸和波数，实际可用地格由本章配置限定。

截至本轮只读核对，团队 main `589c2fc` 的终章九个节点与本地一致，剧情／事件工作项没有新的终章编队或灯具机制答复。本次地图、精英、灯车与援军方案依据用户的自由创作授权实现，不能表述为团队已经确认的正式主线协议。

正式接入候选为 `finale_intro_5 → 战斗 → finale_intro_6`：前者发出行动指令，后者已经叙述照亮仓库、黑影溃退及伙伴撤离。本轮不改动这两个节点，也不让家园试玩提前写入 `finale_started`、`finale_completed`、`kingdom_founded` 或救援标记，不发长期伙伴、家具、货币、物资或鼓励次数。灯车、援军和受困猫的局内表现不自动成为其他模块的新剧情状态。

## 角色职责与本关编队

终章正文明确由墨墨引导视线、点点排查伪装陷阱、团子携灯并协助推进。因此初始六猫保留团子、点点、墨墨，并配绒绒、斑斑和栗栗承担输出与两侧防守。点点保持暹罗辅助形象，斑斑保持奶牛盾卫；既有猫的长期招募时点不由本场名单改写。

喵喵仍固定在 D2 作为保护目标，不攻击、不阻挡、不占初始六猫名额。剧情中的“带队冲锋、推移灯具”在本章表现为防线与光路推进，不把主角改成可拖动的战斗单位。阿策继续使用本地规则顾问，不占编队，也未在本轮接入模型。

本章追加三名固定位置的中途援军：铃铃 B5、桃桃 F5、音音 F4，分别在第 3、5、7 波进入。援军以 `waiting → active → retired` 表示等待、在场和退场，不占六名可移动主力名额；预留格从准备开始不可被主力占用。援军不能拖动、交换或部署，不能因治疗、护盾或补能重新入场。六名主力全部退场仍立即失败，不由剩余固定援军无限拖延战斗。

## Boss、精英与光路

永夜之王固定占据 C9–E11 的 3×3 九格，整块足迹共享一份体力，同次范围攻击只结算一次。影甲卫 B9、鸣影卫 F9 是分别拥有体力的两个精英目标，需要各自被真正击败；不能仅击败巨大 Boss 后忽略仍存活的护卫。

影甲卫提供 Boss 护幕，鸣影卫强化普通小怪。墨墨在本章延续 100 能量的夜视与全队护盾，但夜视的作用改为暂时识破 Boss 护幕，不复用第四章的全场断灯。随着战斗推进，灯车在第 3、5、7 波逐段照亮仓库并削弱护幕，构成与剧情相符的光路。灯车属于本章场景机制，不是随机携带物或玩家库存消耗；不需要事件方补发灯具 ID，也不能因未获得某件 carry 而永久停住推进。

Boss 具有明确预告的整行横扫，进入半血阶段后增加双十字坠击。危险格锁定后不跟随猫移动；玩家可以利用移位、治疗、护盾和技能时机维持防线。新增援军提供支援，但初版平衡需要同时验证“无 carry 可通关”和“不操作不会由援军自动包赢”。

## 参数、结算与恢复

- `attempt.modifiers.shadowPressure` 继续用 −1／0／1 转为 low／medium／high，在重建局内状态时应用一次敌人体力倍率；不重新计算事件评分。
- 可选 `attempt.modifiers.carry` 仍为 `lantern / mirror / bell / box / dog / dove` 六枚举，每场至多一个。第五章灯车和中途猫咪援军不借用 carry 通道、不挤掉事件奖励，也不新增战斗中途推送接口。
- 沿用 `START_BATTLE` 与 `COMPLETE_BATTLE`。局内胜利需要十波小怪全部处理、永夜之王及两名精英均被击败、突破少于三次。L05 胜负报告都必须含 `report: {leaks, bossDefeated, elitesDefeated}`，其中 `elitesDefeated` 是 0–2 的整数，胜利必须为 2；`bossDefeated` 只表示 Boss 本体。旧章仍可省略精英字段，不把本章要求加到旧章。服务报告与校验以[战斗接口](../design/tower-defense/interfaces.md)和 [OpenAPI](openapi.json) 为准，不能伪称服务端逐帧重演。
- 试玩胜利只记录 `finale_boss` 完成并返回家园；胜负均保留主线待用 `PendingModifiers`，不触发大结局或长期奖励。
- 失败结算回本关准备；重试创建新 attempt，并复制失败场次的难度、carry 快照。离开准备页到家园／探索／剧情时清理临时失败身份。
- 标题、顾问、页面隐藏及宿主暂停遵守同一个模拟时钟；整页刷新从同一服务 attempt 的 ready 状态重建，不是逐帧恢复。刷新不会把局内援军入场永久写进玩家猫册。
