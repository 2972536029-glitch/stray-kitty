# 第四章地下通道接入

更新：2026-10-27。第四章在个人分支 `feat/battle-l04-tunnel` 开发，基于事件携带物接入版 `1df12ef`（含团队 main `589c2fc`），依赖前章战斗和 carry 的现有实现。本轮尚未创建第四章 MR，也未合入 main；以前章节的 MR 不代表第四章已交付。

## 独立试玩入口

新增入口 `tunnel_boss`，家园在 `alley_rescued` 后可进入“第四章·地下通道”试玩，无须先完成第二、三章试玩。它是独立战斗场次，不自动接管当前第四章剧情。catalog 的 lanes=5、columns=8、waves=8 表示包围尺寸与波数；棋盘实际只有 37 格，E1–E3 不存在。地形、编队与数值见[地下通道设计](../design/tower-defense/levels/L04-underground-tunnel/design.md)。

正式剧情的候选插入点是 `rescue_intro_6` 之后、`rescue_intro_7` 之前，目前只作为团队对齐方案。已有剧情通过 `rescue_intro_7` 完成救援并返回家园；本轮不改这些节点，不在试玩写入 `tunnel_explored`、`cats_rescued_batch1` 或其他主线标记，也不让试玩胜利强行跳入该剧情。

`BattleHost` 按活动 attempt 的 stage 路由地下通道页面；战斗只读取真实场次快照，不从家园按钮、剧情文案或库存推测难度与携带物。

## 角色与剧情边界

本关六猫为绒绒、斑斑、团子、栗栗、点点、墨墨。点点使用暹罗辅助猫形象，本章归队负责识别绊线和诱饵；这与第三章场外巡视的安排分别按章处理。墨墨负责夜视与团队护盾。喵喵是 C2 的保护目标，既不攻击也不阻挡，不占六猫名额；剧情中的开阀救援动作不等于战斗单位攻击。阿策仍为本地规则顾问，不占编队，模型接入留待战斗章节完成后。

E7／E8 的三号泄洪阀与铁栅配合受困花猫姐妹、幼猫的叙事，只作布景，不增加可部署伙伴、救援奖励或长期招募。第四章不把点点或墨墨当作被救对象。

## 墨墨第四章能力

第四章使用“夜视护行”：消耗 100 能量，恢复全场视野 10 模拟秒，并给全部仍在场猫 45 护盾、持续 8 秒。自然蓄能仍为每秒 5，不使用技能冷却。护盾不治疗、不复活、不累加；与已有护盾取较高盾值、较长剩余时间。第三章继续使用“巡光护行”的护盾＋清除已生成荆棘，不追溯修改前章。本章没有荆棘。

断灯监守的断灯脉冲有 2.5 秒预告，命中后黑暗最多持续 8 秒，之后自动恢复。黑暗只影响远处普通黑影的可见性：距离任一在场猫或喵喵不超过曼哈顿 1 格的黑影仍可见；猫、名字、体力、能量、技能按钮和固定 Boss 机关预告始终清晰。猫的自动攻击、阻挡、移动、蓄能与技能继续生效。没有墨墨、墨墨退场或能量不足时，可以守住近处并等待恢复，不会出现必须开夜视才能受伤的敌人。

界面与军师不在文字、无障碍标签或详情里暴露当前不可见黑影的精确位置与体力。鸽子仍只预告波表，不能据此把所有移动中的黑影显示出来；小灯也不替代墨墨的全场夜视。

## 参数、结算与恢复

- `attempt.modifiers.shadowPressure` 的 −1／0／1 对应 low／medium／high。只在创建战斗状态时应用一次 0.8／1／1.2 敌人体力倍率，其他基础参数不随事件评分重算。
- 可选 `attempt.modifiers.carry` 沿用 `lantern / mirror / bell / box / dog / dove`，每场至多一个。L04 不增加新枚举，不新增战斗中途推送事件的协议；具体效果与来源见[携带物对接](BATTLE-EVENT-CARRY.md)。
- 沿用 `START_BATTLE`、`COMPLETE_BATTLE`。结果报告为 `report: { leaks, bossDefeated }`，胜利要求 Boss 已败且 leaks<3；客户端还须清完八波普通敌人。服务验证阶段、活动场次、报告和幂等，不做逐帧权威重演。
- 胜利只记录 `tunnel_boss` 完成并返回家园，不发物品、货币、家具、鼓励次数或长期伙伴；胜负均保留主线待用 `PendingModifiers`。
- 失败结算回本关准备。重试创建新 attempt，复制失败场次的完整难度与 carry 快照；离开准备返回家园／探索／剧情时清理临时失败身份。
- 标题、暂停与页面隐藏停止局内计时；整页刷新从同一服务 attempt 的 ready 状态重建，不是逐帧恢复。无本波重开、背包、休整或同场复活。

## 地图和操作

左上暗管在 A2 出怪，A1 是可通行的破损管槽；用户补标的 B2 保留为完全阻路的封闭暗管。黑影沿 A2→A1→B1→C1→C2 绕行，不能穿过 B2 贴近喵喵。短路线每波仅一只、延至本波第 8 秒，且不安排厚衣黑影；斑斑默认 C1 守住该线。另两条较长路线从 B8、D8 进入，八波共 32 只，具体难度须结合正常操作验证。

当前美术分支采用潮湿暗道的像素窄砖、排水痕、管线和阀门，保留猫旁技能和紧凑军师入口，不增加伙伴侧栏；外围环境表现地下空间，不作为室外夜景或新增地格。37 个实际地格、9 个障碍、3 个入口、1 个保护格、4 格 Boss，共保留 20 个可部署格。缺失格既不画也不参与点击、部署、路径或技能中心。战斗场景美术由战斗侧承接，页面 UI 与轩扬协作，详见[场景美术](../design/tower-defense/scene-art.md)。
