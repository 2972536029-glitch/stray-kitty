# 随机事件 → 战斗携带物与协助者

更新：2026-10-27。原六种携带物／协助者随 [MR !32](https://school-gitlab.xsolla.dev/haozhe_wang/stray-kitty/-/merge_requests/32) 完成，当前 main 已含 L00–L05 战斗。此次在独立分支 `feat/battle-event-allies` 补齐余尧 [MR !39](https://school-gitlab.xsolla.dev/haozhe_wang/stray-kitty/-/merge_requests/39)／[MR !40](https://school-gitlab.xsolla.dev/haozhe_wang/stray-kitty/-/merge_requests/40) 提出的 `rats / kitten`：正式八枚举沿用原 carry 通道，新增两种局内正面效果。事件卡仍由事件方提供，未修改或合并其分支；详细交接见 [新增协助者说明](BATTLE-EVENT-ALLIES.md)。

携带物接入不重调已有猫咪、敌人、Boss、地图、波表、通关条件或三档难度基础数值。第四、第五章使用各自的新地图与 Boss 配置，同样不为抵消 carry 收益而提高压力。没有 carry 的关卡保持基础规则。事件加成不作为通关必需条件，也不恢复已删除的库存补给、选带背包、用药或复活系统。

## 交接字段

```ts
type BattleCarryId =
  | 'lantern' | 'mirror' | 'bell' | 'box'
  | 'dog' | 'dove' | 'rats' | 'kitten';

// 事件产生一个可选 carry；主流程保存后挂到真实场次。
attempt.modifiers = {
  shadowPressure: 0, // 仍为 -1 / 0 / 1；独立于 carry
  carry: 'lantern', // 可省略；每场至多一个 ID
};
```

原六个 ID 按 MR !24：`lantern / mirror / bell / box / dog / dove`；本轮按事件方 !39／!40 只增不改，追加 `rats / kitten`，合计八个。鸽子必须使用 `dove`。乌鸦尚未列入这版正式枚举，本轮不实现；将来由事件方追加正式 ID 后再接。旧提案 `pigeon / crow` 不作为正式别名接受，收到时按未知加成回退，避免双方长期维护两套命名。

事件负责“哪张卡、哪种结果产生哪个 carry”和叙事来源，主流程负责 `PendingModifiers → attempt.modifiers` 快照、持久化及重试，战斗只消费活动场次快照，不再掷骰、不重算评分、不从库存猜测来源，不在战斗里随机发奖。四种物品来源沿用 MR !23；老黄与鸽子的事件来源沿用 MR !24，不由战斗方另造卡或自动招募。老黄节点卡已经定义，但地图上正式摆点仍需地图方完成。

只有拿到新的有效 carry 才覆盖旧 carry。后续事件没有 carry 字段时保留先前携带物；不能把“无新奖励”解释成“清空旧奖励”。无值或尚未接入的历史 ID 均可按基础战斗继续，事件配置写入仍进行枚举校验。

| 字段／消息 | 提供方 → 消费方 | 约束 |
| --- | --- | --- |
| `EventOutcome.carry?` | 事件 → 主流程 | 一个有效 ID；未发放时省略，不从物资数推导 |
| `PendingModifiers.carry?` | 主流程持久化 | 仅新奖励覆盖，按章节清理或保留 |
| `attempt.modifiers.carry?` | 主流程 → 战斗 | 开战快照，整场不随之后事件修改 |
| `COMPLETE_BATTLE` | 战斗 → 主流程 | 沿用 `attemptId`、`outcome`；L01–L05 必须包含 `report: {leaks, bossDefeated}`；L05 另必报整数 `elitesDefeated`（0、1 或 2），胜利必须为 2，旧章可省略；L00 仍只报 `attemptId` 与 `outcome`。不新增库存耗用、carry 发奖或返还字段 |

镜片“本局已使用”等只属于局内状态；场次结果仍使用原幂等命令，事件方不需要接收逐帧信息。

## 当前效果表

时间均为模拟秒，跟随暂停、标题、页面隐藏及倍速。物品和协助者不占猫咪编队、不增加部署格、不计入敌人／胜负统计。默认入口取该章第一波第一只黑影的真实入口：L01 为 A4，L02 为 A4，L03 为 C8，L04 为 B8，L05 为 A11；固定路线指从该入口生成的那一路。L04 默认入口不取较短的 A2 暗管线。

| ID | 名称 | 本轮战斗效果 | 触发与结束 |
| --- | --- | --- | --- |
| lantern | 小灯 | 默认入口预置一盏灯；以灯为中心，曼哈顿距离 2 格内每只普通黑影每次受到 20 点光伤 | 自动每 4 秒一次，持续本场；不攻击 Boss 或 L05 精英，不新增“必须照亮才可受伤”的判定 |
| mirror | 镜片 | 全场普通黑影停止移动、普攻及普攻计时 3 秒；猫、Boss 与 L05 精英照常行动 | 战斗中手动使用一次；准备／暂停不能使用；不冻结 Boss 预告或特殊地面危险 |
| bell | 铃铛 | 全部在场猫开局各 +20 能量，截顶 100 | 点击开始守护时仅一次；原每秒 +5 与技能消耗 100 不变。当前使用 0–100 能量制，不沿用旧槽位含义的“+2” |
| box | 纸箱 | 第一波默认入口这一路的每只普通黑影，在入口各等待 2 秒后放行 | 每只只拦一次，第一波结束自动移除；不用永久封路，不把能否拆箱当通关条件 |
| dog | 老黄大狗 | 固定路线普通黑影移速 ×0.75 | 持续本场；与铃铃等技能减速取较慢效果，不相乘；不发光、不驱散、不攻击 Boss |
| dove | 咕咕鸽子 | 展示当前／下一波真实入口、怪种与数量；准备时先预告首波 | 只提供情报，不改变波表、倒计时、刷怪或难度 |
| rats | 鼠群小队 | 每 8 模拟秒在本章真实出怪路线间轮巡，当前路线普通小怪移速 ×0.8 | 与技能减速取较慢效果；不减攻击速度、不影响 Boss／精英、不堵路 |
| kitten | 获救小猫 | 每波开始给仍在场且未封能的主力各 +8 能量，截顶 100 | 含第一波，每波仅一次；不补退场猫／固定援军，不自动施放、不产生拾取或库存奖励 |

小灯击退的小怪进入原有击退计数、清波和通关检查。镜片与纸箱的停留有明确上限，过期必须恢复行动；不能把纸箱或协助者当作需要清理的敌人。纸箱不挤占部署位置，避免“先堵住再永远刷不完”的卡关。

这些是战斗侧当前可运行的第一版具体效果。之后可以独立调整事件收益，但本轮不因奖励存在而提高基础关卡数值。

## 接入章节与生命周期

| 入口／阶段 | 接入约定 |
| --- | --- |
| L00 `l00_tutorial` | 不启用 carry，保持五步教学与六波实战；不消费主线待用携带物，历史教学场次也不因携带物跳过教学 |
| L01 `alley_rescue / alley_boss` | 从第一章开始启用。胜利清理主线待用修正；失败结算回原关准备，重试复制失败 attempt 的完整难度与 carry 快照，生成新 ID |
| L02 `market_boss`、L03 `greenhouse_boss`、L04 `tunnel_boss`、L05 `finale_boss` | 四章当前为家园独立试玩；可展示场次携带物，胜负均保留主线 PendingModifiers。失败重试沿用失败快照，胜利只记录本关完成并返回家园 |
| 结束／重试 | 局内计时与镜片使用状态随局结束；失败后的新 attempt 按同一个 carry 重新初始化。离开失败准备去家园／探索／剧情时清理临时失败身份 |
| 标题／整页刷新 | 标题保留原局内实例并停表；整页刷新按同一服务 attempt 和快照重建 ready，不是逐帧存档，carry 不叠加 |

“场次结束清空”指局内效果结束，不能把失败重试所需的快照也清掉。独立试玩不应消费未来主线的待用奖励。后续正式主线入口接入时，生命周期需按对应 stage 明确，不笼统写成所有关胜利都清零。

## 展示与责任边界

战斗上方只增加一条事件带入说明，物品写“从事件带来”，协助者写“动物来报恩”，镜片提供一次使用按钮；无 carry 时不显示该条。小灯、纸箱、鼠群与获救小猫只在实际入口画小标记，不扩展棋盘边界或重新加入伙伴侧栏。

原事件文案／结果卡负责说清来源，战斗不写成系统凭空赠送，也不发长期猫咪或物品奖励。契约、OpenAPI 和服务校验需一起维护；未来新增枚举由双方对齐。本分支只接入开战时的快照，尚无“战斗已经开始后再推送新随机事件替换 carry”的通道。

第四章墨墨的夜视＋全队护盾属于本章伙伴技能，不增加 carry ID，也不要求事件方补发一个“夜视物品”。小灯继续按原半径造成伤害，不额外恢复全场视野；镜片仍只停普通黑影，不暂停 Boss 断灯预告、黑暗或夜视计时；鸽子提供当前／下一波配置情报，不暴露黑暗中移动黑影的精确坐标。黑暗会自行恢复，八种 carry 都不是解除黑暗或通过关卡的必需条件。第三章墨墨的护盾＋清荆棘保持原样。

第五章的灯车、九格 Boss 护幕与中途固定援军属于本章关卡规则，不新增 carry ID、事件来源或库存消耗；它们可与一个事件 carry 同时存在。铃铛仅给开局已在场六主力一次能量，不在援军入场后重复发放；音音的周期补能属于固定援军能力。小灯、镜片、纸箱、老黄仍只影响普通小怪，不让 L05 精英或 Boss 被当成普通小怪处理。鸽子只预告普通波表，不替代精英状态或灯车阶段说明。第五章结果必须分别如实报告 Boss 本体和两名精英，不能因事件加成跳过通关目标。

基础规则见[战斗接口](../design/tower-defense/interfaces.md)，现有补给取消与旧存档处理见[物品说明](../design/tower-defense/items.md)。
