# 鼠群与获救小猫：事件协助者接入

2026-10-27，分支 `feat/battle-event-allies`。本次补齐 `rats / kitten` 的战斗消费能力，不调整猫、敌人、首领、地图、波表或三档基础数值。

## 事件来源与代码状态

事件来源以余姚 [!39](https://school-gitlab.xsolla.dev/haozhe_wang/stray-kitty/-/merge_requests/39) 的 `7eb752f`、[!40](https://school-gitlab.xsolla.dev/haozhe_wang/stray-kitty/-/merge_requests/40) 的 `805b6b2` 为核对依据：

- `rats`：暗道《岔口的小道消息》大成功，接续 `rats_truce` 分粮友好链；鼠群成为侧翼协助者。
- `kitten`：仓库《失踪猫的窝》喂食线大成功，获救的小猫在后续守护中回报帮助。
- 应急灯闸／灯具箱的 `lantern` 继续使用原小灯效果。

事件分支已经增加 Go、内容校验和 OpenAPI 的新 ID，但原战斗实现只接受六种 ID，收到这两种时会提示未知并按基础关继续。复用传递通道不会自动产生新效果。本次补齐 TypeScript 契约、名称／图标、引擎、入口标记与回归检查；独立分支也携带与事件方相同的 Go／内容／OpenAPI 枚举增量，以便当前 main 可单独校验和评审。没有改动事件卡、概率、卡池、地图节点或他人分支。

## 战斗表现

| 协助者 | 实际效果 | 限制 |
| --- | --- | --- |
| 鼠群小队 `rats` | 从本章第一波真实入口出发，每 8 模拟秒轮换到下一条实际出怪路线；当前路线普通黑影移速 ×0.8 | 与猫咪减速取较慢效果，不相乘；不改变黑影攻击计时，不影响 Boss／终章精英，不封路、不新增敌人或部署格 |
| 获救小猫 `kitten` | 每波开始时给仍在场且未封能的主力猫各 +8 能量，最多 100；包括第一波 | 同波不重复，退场猫不补能、不复活；封能时跳过且不延后补发；终章固定援军不获得能量字段；技能仍需玩家手动释放 |

小猫采用每波固定补能，不引入新的概率、光弹掉落、拾取或库存奖励系统。技能仍按每模拟秒 +5 自然蓄能；这两种事件收益都不是通关必需条件。鼠群与老黄的差异是“轮巡各路”和“持续守住固定一路”。

两种协助者均显示“动物来报恩”，附真实入口的小型友好动物标记。鼠群提示当前入口和换路倒计时，小猫提示最近补能波次。标记不读取第四章隐藏敌人位置，不改变断灯／夜视。

## 通道与生命周期

只读取 `attempt.modifiers.carry`，正式 ID 扩为八种，不增加命令或结算字段。未获得新 carry 时保留旧奖励，只有有效新奖励覆盖旧值；不会从库存或角色名单推测来源。

- L00 教学继续不启用 carry，也不消费主线待用奖励。
- L01 主线胜利按既有规则清理待用修正；失败保留，重试建立新 attempt 并复制旧快照。
- L02–L05 目前的家园独立试玩，胜负都保留主线待用修正；失败重试复制旧快照。正式剧情入口接入后按入口身份对齐，不笼统承诺所有关胜利清零。
- 暂停、聊天、标题、页面隐藏与倍速沿用战斗模拟时钟。整页刷新仍重建同一 attempt 的准备状态，不是逐帧恢复；不会叠加此前局内补能。
- 未知 ID 仍提示后按基础战斗继续，不能卡住开战。

墨墨沿用双方约定的“事件中的日常听声／探水 → 第四章战前觉醒夜视＋护盾”叙事口径；本次不宣称主线觉醒剧情已接通，不更改伙伴技能、第三章清荆棘、剧情接点或 flags。
