> 基于 main@e95c618 全量实测验证;本地服务 http://127.0.0.1:5017
> 预计时长 8~12 分钟;每幕含【操作】和【一句话讲解词】
> **v2 变化**:开场直接连教学战(无准备间隔);小巷换成 SVG 新地图;随机事件改为"走进随机区"触发(每区一次 55%,三区至少一个的概率 91%,演示比以前可靠得多)

## 开演前 60 秒准备

- 起 `npm run dev`,开浏览器 127.0.0.1:5017,验收工具栏**保持关闭**
- **新建档演示**(提前清好,别让观众看见重置)
- 备一手:出事就刷新(F5),存档在服务端,进度不丢

## 第一幕 · 开场与序章(90 秒)

【操作】开始冒险 → 连点继续故事
【讲解词】"玩家扮演家猫喵喵,追金枪鱼走失。全程猫咪视角,人类只以寻猫启事这类痕迹出现——这是我们的叙事红线。"

## 第二幕 · 序章教学战(3~4 分钟)★琦雯主场

【操作】剧情结束**直接进入战斗**(九步教学,跟着引导走)
【讲解词】"剧情和战斗是无缝衔接的。九步教学教部署、治疗、补能、技能,全程新手保护怎么打都不会死。右上可以调速。"

【操作】指右侧军师区域
【讲解词】"这是军师阿策——战斗内的问答助手,问它'谁需要治疗'会给建议但不会替你执行,决策权始终在玩家手里。"

【预案】时间紧就打到五六波切话术:"十波全程约五分钟,完整版随时可玩";Esc 退出不丢进度,刷新恢复同一战斗场次

## 第三幕 · 新雨巷探索与随机区(2 分钟)★你的主场+Jenny 地图

【操作】教学战胜利后回到巷子(SVG 新地图)→ 走向画面中的纸箱,按 E
【讲解词】"这是全新的矢量雨巷地图,有真实的碰撞和寻路。触发是双轨的:纸箱这种是'你去找事';"

【操作】往地图另外方向走,穿过一块开阔区域
【讲解词】"——而走进这三块随机区,'事来找你':每区一次 55% 的相遇判定,服务端掷的。屏幕一暗,就是撞上了。"

【操作】随机事件:选一项 → 先指"伙伴鼓励"按钮再掷
【讲解词】"2d6 四档判定,失败不惩罚、剧情继续走。伙伴鼓励是掷两组取优,要不要花掉它是玩家第一个真实决策——刚才教学战首通攒回了一枚,现在正好用。"

【预案】三区全空概率 9%:别硬等,继续讲纸箱线,随机事件"演示版随时可以再遇到"

## 第四幕 · 救援结算与花房(90 秒)

【操作】纸箱事件后开始守护 → (战斗,可简短)→ 带伙伴回家 → 寻猫启事剧情 → 花房
【讲解词】"救援成功:点点入队、猫窝进家、首通奖励邮票——主线伙伴确定性获得,不进任何随机池。"

【操作】猫国商店买蓝色饭碗 → 摆到窗边
【讲解词】"邮票只换家具装饰,不卖强度;存档在服务端,刷新继续。"

## 第五幕 · 午夜集市与收尾(90 秒)

【操作】章节地图 → 前往午夜集市 → 走动
【讲解词】"第二章集市危险度更高,事件密度和风险占比都不一样——同一个系统,两张地图两种性格。这里走路仍按里程触发,和小巷的随机区是两套入口、同一个池子。"

【收尾话术】"从一行 README 到今天:序章+前两章、两场战斗、18 张事件卡、SVG 地图全部贯通;第三章花房建设是下一步。谢谢大家。"

## 数字弹药(被问到时用)

- 事件卡 18 张约 200 段结果文案;四档概率 2.78/25/44.44/27.78
- 双触发入口:小巷随机区(55%×3 一次性)+ 集市里程制(150px/段,危险度概率)
