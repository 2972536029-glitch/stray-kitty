# 战斗美术分章交付

公共分支 `feat/battle-art-core` 基于 `main` 的 `f74e6d1`，提供材质图集、场景绘制工具、棋盘外布景、沉浸式 HUD 样式、自适应尺寸和事件支援紧凑展示。公共分支本身不启用任何章节的新页面。

六个章节分支都从同一个公共底座建立，互不依赖。每章只增加对应 painter、viewport 和本章范围文档；准备评审时先以公共分支为目标，公共底座合并后可改为 `main`，避免重复评审共享代码。

| 分支 | 独立内容 |
| --- | --- |
| `feat/battle-art-l00` | 序章雨巷、六波教学页面与必要操作可见性 |
| `feat/battle-art-l01` | 第一章雨后小巷、四猫与巷口首领场景 |
| `feat/battle-art-l02` | 第二章地下午夜集市、暖灯与三类摊位 |
| `feat/battle-art-l03` | 第三章废弃花房、温室玻璃与花架植物 |
| `feat/battle-art-l04` | 第四章地下通道、暗管、断灯与夜视表现 |
| `feat/battle-art-l05` | 第五章总仓库、九格首领、双精英和援军场景 |

`feat/battle-scene-art` 保留六章同时可玩的集成效果。分支创建不表示已创建 MR 或合入主分支。验收应区分：单章分支的构建／类型检查，与集成版的六章浏览器流程、教学、技能菜单、断灯及援军机制验证。

美术按每章剧情区分环境和天气，共同表现约定见[场景美术说明](../scene-art.md)。原地格、路径、数值、出怪、技能效果与胜负条件不在本轮调整范围。
