# 战斗美术分章交付

公共分支 `feat/battle-art-core` 已同步 `main` 的 `575aa3f`，提供材质图集、场景绘制工具、棋盘外布景、沉浸式 HUD 样式、自适应尺寸和八种事件支援紧凑展示。公共分支本身不启用任何章节的新页面。

六个章节分支都从同一个公共底座建立，互不依赖。每章只增加对应 painter、viewport 和本章范围文档；准备评审时先以公共分支为目标，公共底座合并后可改为 `main`，避免重复评审共享代码。

2026-10-28 的共享更新采用普通合并同步到六个章节分支：支援像素标记统一贴地阴影，紧凑面板保留鼠群巡逻倒计时与获救小猫补能状态。章节之间不互相合并，不重建六章集成分支。阿策模型问答另由 `feat/battle-advisor-model` 交付；组合试玩不代表模型代码已进入美术分支。
