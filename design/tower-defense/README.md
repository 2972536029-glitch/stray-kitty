## 当前流程

序章剧情 → `l00_tutorial` 新版 L00 教学 → 第一章雨后小巷探索／纸箱事件 → `alley_rescue` 四猫 L01 首领战 → 原救援剧情与家园。家园 `alley_boss` 是同一 L01 的重玩入口。三个 ID 是服务入口，不是三套战斗地图。

战斗页面保留奶油浅绿棋盘、左侧军师、猫旁技能和速度／暂停；原休整区改成伙伴状态。地图外不添加场景背景。第一章棋盘从 12 列／30 格收缩到 10 列／26 格；地图组的自由探索场景是另一套坐标，未随战斗棋盘缩放。

## 后续章节推进方向

L02–L05 未实现。本轮仅调整 L00／L01；后章的地图、阵容、特殊怪、技能和道具安排须逐章重新确认，旧“进阶治疗／补能物品、军需官、休整恢复”构思不能作为当前两章的运行规则或自动开工清单。仍保留每个正式章节一名 Boss、随章节逐步增加挑战的方向。
