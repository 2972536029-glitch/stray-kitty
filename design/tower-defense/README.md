## 后续章节推进方向

记录于 2026-10-26。以下为已对齐的整体推进参考，供以后逐章设计时统筹；L02–L05 仍未实现。本次只记录方向，不创建关卡、角色、物品或敌人机制。具体地图、数值、阵容、解锁入口和机制随各章任务确定。

| 章节 | 推进方向 | 设计重点 |
| --- | --- | --- |
| 第二章 L02 | 解锁第一种进阶道具，并引入一种新的功能性小怪 | 当前优先考虑呼噜浓汤；首次特殊应对要清楚、容易理解，并允许失误 |
| 第三章 L03 | 解锁另一种进阶道具，小怪回到熟悉的普通类型 | 当前优先考虑猫薄荷香囊；第二章的功能怪暂不登场，给玩家消化道具与技能配合的空间，可用路线、出怪节奏和 Boss 保持挑战 |
| 第四章 L04 | 再引入一种新的功能性小怪 | 要求更主动地看动作、保留技能与调整站位；与第二章机制形成区别，具体类型待设计 |
| 第五章 L05 | 留待前四章实际试玩后细化 | 可评估组合已熟悉的机制；不预定新怪数量、是否混编全部机制或具体 Boss 方案 |

两种道具按“先加强治疗、再加强补能”作为当前优先顺序，允许结合关卡试玩调整；道具设计仍见[补给与奖励](items.md)。解锁不等于免费赠送，也不要求靠随机掉落才能过关，仍须有合理的空包通关方法。

功能性小怪围绕猫咪的特殊能力设计，使侦察、控制、承伤和支援各有发挥空间。可探索显形后可攻击、可通过减速争取处理时间、可读攻击动作配合护盾或移位等方向；这些只是候选，不据此确认某章必出隐身怪、指定乌乌登场或实现具体技能。

设计时把敌人和可用应对方式一起考虑：开战前保证玩家有能应对的猫或方法，提示清楚，并保留失误后的下一次处理机会。若探索显形机制，必须避免“技能没能量、只剩无法攻击的隐身怪、又只能靠普攻蓄能”的死局，也须考虑对应猫休整时如何恢复应对能力。

整体节奏按“引入一种应对 → 消化已有玩法 → 再增加一种应对 → 结合试玩决定综合考验”推进。每关一个 Boss、逐章增强的约定继续保留，增强可体现在判断与配合；页面和猫旁技能操作继续沿用 L00 范本，具体变化仍需说明玩法、补给和通关条件的影响。
