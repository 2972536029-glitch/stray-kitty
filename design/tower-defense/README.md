第一章六猫为绒绒（远程）、斑斑（盾卫）、栗栗（近程）、桃桃（近程）、铃铃（控制）、音音（辅助），全部保留单目标普攻。普通敌人为巡逻、疾行、厚衣三类黑影，另有固定 2×2 路障首领。页面以序章 L00 为范本，技能仍从场上猫旁圆钮查看与释放；有效棋盘外留空，地图场景与团队 UI 对齐由对应成员负责。

第一至第五章每个战斗关卡一个首领，同难度下逐章增强；允许小怪在关卡容错范围内突破，胜利必须实际击败首领。第一章首领固定不移动；具体后章形状、数值和机制尚未设计，不将规则声明写成五章均已实现。
