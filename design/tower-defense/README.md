## 协作边界

战斗维护地图规格、数值、局内模拟、教学与补给目标规则。UI 负责家园仓库和装配展示；主流程协调服务端的保存、预留、耗用、返还及发奖，不能全部归给 UI。事件侧负责根据事件结果判断战斗档位，主流程／宿主统一转换并传入 low／medium／high；战斗侧提供三档数值与接口，同一场次保持传入档位，不重复计算事件得分。地图按固定章节规格制作，影响格子、通行、部署或攻击的变化须同步战斗规则。

源独立仓库的整树合并限制属于首次交付历史；当前是以 main 工程为基础的真实集成分支，保留原 workspace、服务端与验证流程。首次正式合入后以主项目为唯一生产实现，不并行维护两套生产代码。
