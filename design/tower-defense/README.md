## 当前流程

序章剧情 → `l00_tutorial` 新版 L00 教学 → 第一章雨后小巷探索／纸箱事件 → `alley_rescue` 四猫 L01 首领战 → 原救援剧情与家园。家园 `alley_boss` 是同一 L01 的重玩入口。完成首次救援后，可分别进入 `market_boss` 第二章独立试玩和 `greenhouse_boss` 第三章独立试玩，无须先赢第二章才能试第三章。原第二章剧情／探索按钮继续原流程，两个试玩均不自动接入正式主线。五个 ID 对应四套战斗地图。

战斗页面保留奶油浅绿棋盘、猫旁技能和速度／暂停；四章均无伙伴列表侧栏，军师为棋盘上方紧凑入口。地图外不添加场景背景。第一章棋盘为 10 列／26 格；第三章严格使用 34 个真实格，6×9 仅表示包围框，缺失格不绘制、不点击、不部署或作为技能中心。地图组的自由探索场景使用另一套坐标。

第二、三章试玩只记录本关完成，不发物资、长期伙伴或鼓励奖励，不推进剧情，也不清理主线待用 `PendingModifiers`；失败重试沿用失败场次的难度快照。

## 后续章节推进方向

L02 使用七入口与单格 Boss；L03 使用三入口、四格 Boss 和锁定位置后生成的荆棘，墨墨替代点点提供护盾与清场支持。L04–L05 尚未实现。后章规则须逐章确认，旧“进阶治疗／补能物品、军需官、休整恢复”构思不是当前运行规则或自动开工清单。每章一名 Boss，各章人数、入口与机制分别设计，不要求所有数值逐章同时增加。

军师继续使用本地规则，全部战斗章节完成后才考虑模型接入。各章的战斗能力与上阵名单不自动改写长期招募、剧情身份或入队时点。
