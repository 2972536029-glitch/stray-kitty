## 当前流程

序章剧情 → `l00_tutorial` 新版 L00 教学 → 第一章雨后小巷探索／纸箱事件 → `alley_rescue` 四猫 L01 首领战 → 原救援剧情与家园。家园 `alley_boss` 是同一 L01 的重玩入口。家园增加 `market_boss` 第二章独立试玩，原第二章剧情／探索入口继续原流程，正式战斗插入点待团队对齐。四个 ID 对应三套战斗地图。

战斗页面保留奶油浅绿棋盘、猫旁技能和速度／暂停；三章均移除伙伴列表侧栏，军师改为棋盘上方紧凑入口。地图外不添加场景背景。第一章棋盘从 12 列／30 格收缩到 10 列／26 格；地图组的自由探索场景是另一套坐标，未随战斗棋盘缩放。

## 后续章节推进方向

L02 本轮制作六猫／七入口／单格 Boss；L03–L05 未实现。后章规则须逐章确认，旧“进阶治疗／补能物品、军需官、休整恢复”构思不是当前运行规则或自动开工清单。每章一名 Boss；L02 多入口增加站位压力，同时降低 Boss 体力和直接伤害，不要求所有数值逐章同时增加。

军师继续使用本地规则，全部战斗章节完成后才考虑模型接入。各章的战斗能力与上阵名单不自动改写长期招募、剧情身份或入队时点。
